# Notice — DPO Adapter

This package adapts the Minerva language-model family created by Sapienza NLP
at Sapienza University of Rome. Parent:
`sapienzanlp/Minerva-7B-instruct-v1.0`, revision
`d1fc0f0e589ae879c5ac763e0e4206a4d14a3f6d`, recorded by the parent
repository as Apache-2.0.

The cumulative training lineage includes material from Biblioteca Italiana,
Italian Wikisource, Liber Liber, Project Gutenberg, Oxford Text Archive / ILC,
and PAISÀ. Each source retains its own attribution, license, public-domain,
commercial-use, ShareAlike, and edition conditions. Source disclosure does not
create one package-wide data license and grants no corpus-redistribution right.
