# License Scope

This repository contains artifacts with different rights and redistribution
conditions. No single license covers the complete tree.

## Apache License 2.0

After affirmative approval in `release/artifact_rights_manifest.csv`, `LICENSE`
(Apache-2.0) covers only the approved Leonardo-owned software in `src/`,
`scripts/`, and `tests/`; approved demo code in `demo/`; approved CI in
`.github/workflows/`; and approved Leonardo-owned executable configurations.
Directory membership alone is not a rights decision. The grant does not cover
third-party code unless its file and governing terms explicitly say so.

## Creative Commons Attribution 4.0

`LICENSES/CC-BY-4.0.txt` covers only Leonardo-owned prose, reports, aggregate
evidence, tables, and plots explicitly approved as `CC-BY-4.0` in
`release/artifact_rights_manifest.csv`.

Embedded third-party passages and generated model output remain excluded even
when they appear inside an otherwise CC-licensed report.

## Not licensed by these grants

Neither repository license covers third-party corpus content or metadata beyond
its permitted source-specific reuse; pretrained-model material; generated
poems; raw model output; preferences; votes; annotations; checkpoints; adapters;
optimizer or scheduler state; private mappings; tensors; or any artifact not
affirmatively approved in the release manifest.

Consult `NOTICE`, `DATA_SOURCES_AND_ATTRIBUTION.md`, and the two release
manifests before reuse. A pending or unresolved manifest row grants no rights.
